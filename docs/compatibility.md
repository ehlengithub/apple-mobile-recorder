# 兼容性与验收范围

核对日期：**2026-10-30**。本项目流程为：电脑接收 AirPlay 屏幕镜像并录制点击 → ESP32-S3 通过 USB 绝对鼠标执行 → 导出固件后离线循环。**目前真实页面验收仅限iPad14,3，不代表全机型适配。**

## 三种结论分开看

| 层级 | 可以确认 | 不能据此推断 |
| --- | --- | --- |
| 通用协议设计 | AirPlay 提供画面，USB HID 绝对坐标提供指针输入；离线保存坐标和时序 | 每台设备均接受当前 HID 描述符，或所有线材、转接器均兼容 |
| 苹果官方支持鼠标 | iPhone/iPad 可通过辅助触控使用有线指针设备，官方列出 Lightning、USB-C 接入路径，USB-A 设备需要转换器。[官方说明](https://support.apple.com/zh-cn/111775)（检索：2026-10-30） | 苹果已认证本项目 ESP32-S3，或已保证其绝对坐标、录制和离线功能可用 |
| 本项目实测 | iPad14,3；USB/HID 接 iPad，COM 接 Mac；电脑侧使用 Apple Silicon Mac | 其他 iPhone/iPad、Lightning 组合及 Windows/Linux 已完成端到端验收 |

## 设备与平台边界

| 组合 | 本项目状态 | 使用前要求 |
| --- | --- | --- |
| iPad14,3 + 已用板卡、线材 + Apple Silicon Mac | 有真实页面验收，具体固件版本见下表 | 保持原起始页、方向、缩放和辅助触控设置 |
| 其他 USB-C iPad / USB-C iPhone | 官方有鼠标接入路径；本项目未逐机验收 | 核对数据线、USB 枚举、供电、解锁授权与辅助触控，再单独验证点击 |
| Lightning iPhone / iPad | 官方有有线指针设备接入路径；本项目硬件兼容未核实 | 需匹配机型的转接与供电方案；不承诺当前板卡经任意转换器即可工作 |
| 其他 Mac（含 Intel） | 不在本次实测范围 | 单独验证接收画面、输入与离线导出完整流程 |
| Windows / Linux | 有通用设计或代码路径；未端到端验收 | 接收器、依赖、USB/HID 和完整录制回放均需另验 |

上表涉及 USB-C/Lightning 鼠标的官方依据：[指针设备与辅助触控](https://support.apple.com/zh-cn/111775)（检索：2026-10-30）。**USB-C 接头能插入，不等于本项目必定支持；协议设计不代替具体硬件验收。**

## 当前六步时序与验收

| 版本 | 六步间隔，单位秒 | 证据边界 |
| --- | --- | --- |
| 早先六步版 | `1.435, 0.500, 0.500, 0.500, 0.500, 2.588` | 用户观察真实 iPad 页面后确认正常 |
| 当前首步 3 秒版 | `3.000, 0.500, 0.500, 0.500, 0.500, 2.588` | 仅完成编译、烧录、板端自检；**尚无页面验收** |

本次文档按项目负责人给定的验收边界记录。编译、烧录、自检、指令日志或周期正确，均不能证明页面已选中、提交成功或没有点偏，也不能替代当前版本的页面验收。

当前六步版保持 **350ms 定位稳定、60ms 按压、释放后至少等待 90ms**。间隔按相邻定位动作起点计时，半秒节奏已包含这三段，不再额外叠加；首步 3 秒也用于第六步返回下一轮第一步。稳定循环理论周期约 `7.588s`，不含启动倒计时及 USB 调度误差。

## 部署与坐标限制

- **COM** 是本板连接 Mac 的串口/供电口；**USB/HID** 是连接被控 iPad 的原生 USB 鼠标口，两者不可替代。
- 电脑端画面必须来自 HID 所接的同一台设备。显示另一台设备的画面，无法保证点击落在所见页面。
- 绝对定位避免相对位移累积漂移，不代表跨设备可复用坐标。更换设备、方向、显示缩放或页面布局后，应重新录制并逐步验收。
- 当前电脑录制与离线方案不要求在 iPhone/iPad 安装配套 App，也不要求 Apple 开发者签名。板端固件部署仍是独立步骤。
- 首次部署需保持 COM 供电，待 HID 已连接后，仅拔插 HID 解除持久待机锁；详见[排障文档](troubleshooting.md)。
- 离线循环没有画面输入，不能识别弹窗、列表到底、页面失败或按钮变化；网页急停也不能控制板内离线循环。
