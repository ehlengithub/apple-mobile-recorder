# 通用离线点击执行器

基于 ESP32 iPhone Agent by Henry Yuan，保留根目录 LICENSE 与 NOTICE。

此目录是**源模板**。默认 `macro_data.h` 的步骤数量为0，不含可执行的用户录制。不要手改共享头文件；工作台为每次生成复制独立源码并导出对应项目。

## 输入与时序

- USBHIDAbsoluteMouse，坐标0～32767，由项目0～1坐标转换。
- 每次先定位并等待350ms，再按住60ms后释放。
- 每步间隔按相邻定位动作起点计时；释放后至少90ms，默认最短500ms。
- 项目可配置启动倒计时与轮数；0轮代表持续循环。有限轮数完成后释放并停止。
- `ReplayTiming`中的默认旧档仍保留1000ms间隔下限与300ms释放等待；工作台生成的独立项目显式给出时序参数。

## 启动与停止

每次生成有新部署编号，首次启动把待机锁写入NVS。保持COM供电，等HID连接后，仅拔下USB/HID并重新插入启用。之后可按项目设定独立执行。

按实体BOOT停止，松手不恢复；也可拔USB/HID。EN/RESET可能重启循环。USB休眠、报告发送失败会停止，不自动续跑半轮。

串口命令 `status` 返回状态，`stop` 停止，`dryrun` 在部署待机时用虚拟时间跑两轮，不发送任何点击。打开COM可能触发硬件复位，不能当作无干扰观察手段。

## 构建与限制

工作台调用Arduino CLI，参考core3.3.12及根目录FQBN。编译产物、私有项目和备份全部在本机数据目录，不提交Git。

离线只支持点击；不读取屏幕，不识别界面变化或业务成功。换设备、方向或缩放后单独录制。完整操作见[项目README](../../README.md)，模型与构建接口见[架构说明](../../docs/architecture.md)。
